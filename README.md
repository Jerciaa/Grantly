# Grantly 🚀

A web platform built to simplify tracking, managing, and showcasing digital projects cleanly and efficiently.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://grantlyjerciaa.netlify.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## 📌 About The Project

**Grantly** provides a modern, accessible interface for presenting and organizing digital projects. Built with user experience and quick navigation at its core, Grantly allows users to highlight key project milestones, centralize essential resources, and share updates seamlessly.

### ✨ Key Features
* 📱 **Responsive Design:** Optimized layout for desktop, tablet, and mobile viewing.
* ⚡ **Fast & Lightweight:** Fast load times with streamlined assets.
* 🎯 **Centralized Hub:** Link project assets, documentation, and external links in one accessible interface.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting & Deployment:** Netlify
